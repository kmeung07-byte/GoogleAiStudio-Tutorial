# GoogleAiStudio-Tutorial
Gemini API의 사용법을 익힙니다.

## 프로젝트 구성

- [gemini-31-tts](./gemini-31-tts/README.md): `gemini-3.1-flash-tts-preview` 모델을 이용한 텍스트 음성 변환 (Text-to-Speech)
- [gemini-35-stt](./gemini-35-stt/README.md): `gemini-3.5-transcribe` 모델을 이용한 음성 인식 및 전사 (Speech-to-Text)
- [youtube-stt-web](./youtube-stt-web/README.md): 유튜브 영상 URL 입력 시 오디오 다운로드 및 트랜스크립트 추출 웹 서비스
- [youtube-ai-search](./youtube-ai-search/README.md): 유튜브 영상 임베드, Gemini 3.5 Transcribe 전사, Gemini 3.8 Flash 기반 내용 검색 및 특정 위치 점프 재생(Play), Q&A 웹 서비스
